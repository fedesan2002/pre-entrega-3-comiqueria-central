# Comiquería Central - Pre-Entrega 3



## Descripción

Simulador de compras de una comiquería desarrollado con JavaScript.

El usuario puede ingresar un cómic o manga, indicar la cantidad y su precio. El simulador calcula el subtotal, aplica un descuento y muestra el total de la compra.

La interacción se realiza mediante `prompt`, `alert` y `console.log`.

## Funcionalidades

- Ingreso del nombre del cliente.
- Ingreso del cómic o manga.
- Ingreso de cantidad y precio.
- Descuento del 5% al comprar 2 unidades.
- Descuento del 10% al comprar 3 unidades o más.
- Cálculo del total de cada producto.
- Cálculo del total final de la compra.
- Posibilidad de agregar varios productos.

## Conceptos aplicados

- Función declarada.
- Función expresada.
- Función flecha.
- Parámetros y argumentos.
- Uso de `return`.
- Variables con `const` y `let`.
- Condicionales.
- Ciclo `while`.
- Entrada de datos con `prompt`.
- Salida de resultados con `alert` y `console.log`.
